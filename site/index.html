VPS Deals: Both Hosts Give You the Private Network Free — Only One Charges You for Traffic Between Your Own Servers

Read off the hosts' own documentation on 2026-10-25. The private network is free at both: DigitalOcean — \"traffic on them doesn't count against bandwidth usage\"; Hetzner — \"We do not charge for our Cloud Networks\" and \"The traffic on the private network interfaces is free.\" The split is in what each host counts. DigitalOcean: \"Any data transfer sent by a Droplet using a public network interface counts against the transfer pool for that Droplet's team\" — so two Droplets in the same datacenter swapping 2,048 GiB over their public IPs burn 1,048 GiB of a $4-plan pool and cost $10.48; over the VPC they cost $0. Hetzner: \"Incoming and internal traffic is free,\" and internal is defined to include \"Other Hetzner Cloud servers with the same network zone via their public IPs\" — so the same traffic is already free there, and because \"all subnets within a Network also have to be from the same network zone,\" a Network can never carry the cross-zone traffic that Hetzner does bill. Conclusion: at DigitalOcean the private network saves you bandwidth money; at Hetzner it saves you nothing on traffic and everything on isolation. Also published nowhere else: DigitalOcean's managed NAT gateway costs $40.00/month for 2 Gbps and 100 GiB, its marginal rate equals the public overage rate of $0.01 per GiB, and \"Any existing Droplet data transfer allotment does not apply to traffic through NAT gateways\" — a premium of $39.00 + $0.01 × GiB over just using the public interface you already have. Plus capacity: Hetzner caps you at 3 networks per server and 100 attached resources per network (300 reachable); DigitalOcean caps a VPC at 10,000 resources.

VPS Deals: You Can Downgrade the CPU and the RAM. You Can Never Shrink the Disk — and the Lock Costs $72 to $768 a Year
